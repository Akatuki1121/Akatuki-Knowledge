## Limitations

- This is a second database in the same Cloudflare account, not an off-account backup.
- Cloudflare's internal `_cf_KV` table is platform-managed and was not copied.
- The D1 API denies `PRAGMA integrity_check` with `SQLITE_AUTH`, so that specific check could not be run. The row/schema comparisons and foreign-key check did pass.
- No restore was executed against production, and no production D1 data, Worker settings, secrets, or deployment were changed.
- The separate recovery database consumes D1 storage/quota and should be retained until the rollout and rollback window are complete.
