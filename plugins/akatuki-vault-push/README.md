# Akatuki Vault Push

保管庫（Obsidian）で編集したノートだけを、編集が落ち着いて数秒後に Akatuki Knowledge へ送る小さなプラグインです。反映が次の正時の取り込みまで遅れるのを短くするためのもので、正時の全体取り込みは安全網としてそのまま残ります。

## 動き

- `vault.on('modify')` で変更を受け取り、パスごとに数秒待ってから送ります。連続した編集は最後の 1 回にまとまります。
- 送るのは `.md` ファイルだけです。本文は `vault.read` で読み、SHA-256 を付けて `POST /api/sync/push-note` へ 1 件だけ送ります。
- サーバー側が `unchanged` か `applied` を返した内容は、同じ内容では送り直しません。Akatuki Knowledge から保管庫へ書き戻された内容も、ここで止まります。
- 新規作成・改名・削除は送りません。正時の取り込みに任せます。同一性の照合はサーバー側が YAOS の対応表を引いて行います。
- 一時的な失敗（通信の失敗・429・5xx）は間隔を広げて最大 3 回まで送り直し、それでも届かなければその場では諦めます。無制限にはため込みません。認証の失敗（401）は送り直さず、設定の見直しを促す表示を出します。
- 常時接続や定期的な見回りはしません。送るのは変更があったときだけです。

## 設定

- 有効・無効の切り替え
- 受け口の起点（初期値 `https://akatuki-knowledge.sousou-e1121.workers.dev`）
- 認証トークン（Akatuki Knowledge の API トークン。プラグイン設定の `data.json` にだけ保存され、通信以外では使いません）
- 待ち秒数（初期値 5 秒）
- 最後に送った日時と結果の表示

## 開発

開発用の保管庫で作ってください。本番の保管庫では開発しないでください。

```sh
npm install
npm run build   # main.js を作ります
```

できあがった `main.js`・`manifest.json` を、保管庫の `.obsidian/plugins/akatuki-vault-push/` へ置いて有効にします。

スケジューラ（待ち時間と送り直しの決まり）の検証は、リポジトリ側の `scripts/test-vault-push-plugin.mjs` で行います。
